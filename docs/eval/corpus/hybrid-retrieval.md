# 混合检索与加权 RRF

混合检索同时运行关键词分支和向量分支，再把两路结果融合。关键词分支擅长精确术语和编号，向量分支擅长语义相近但用词不同的表达。把两者组合，通常比任何单一路径都更稳。

关键词分支使用稀疏向量表示词元权重。文档侧先统计词频，权重为 1 加自然对数 tf；查询侧每个唯一词元权重为 1。Qdrant 的稀疏向量启用 IDF modifier，让常见词自动降权，配置编号 KV-BM25-BRANCH 用来标识这一分支。

中文没有天然空格分隔，因此切词采用连续 CJK 片段生成重叠二元组，单字保留，拉丁字母和数字连续片段长度至少为 2，编号 KV-BIGRAM-2。例如「混合检索」会生成「混合」「合检」「检索」三个词元。这样既能覆盖多数中文词组，又不需要引入外部词典。

词元哈希使用 FNV-1a 32 位并映射到 1 到 uint 最大值减一，编号 FNV-1A-32。同一词元在不同进程中必须得到相同哈希，不能使用运行时随机化的字符串哈希，否则写入和查询会对不上。

融合使用应用层加权 RRF。加权 RRF 的平滑常数是 60，配置编号 KV-RRF-60。每条查询的每个分支按排名贡献分数，公式为权重乘以 1 除以 60 加排名，同一文档在多路命中时累加。原问题权重固定为 1，改写查询权重默认为 0.8。

RRF 只看排名，不看原始分数。不同检索分支的原始分数不可直接比较，向量余弦值可能集中在 0.7 到 0.9，关键词得分却没有固定上界；把分数直接相加会让某一路主导结果。只使用排名可以把两路拉到同一尺度。

融合结果按总分降序排列，同分时先比最佳排名，再按切片 ID 升序兜底，保证每次运行顺序稳定。关键词权重设为 0 时，融合结果与纯向量检索一致；向量权重设为 0 时，只保留关键词命中。

稀疏分支故障时不应拖垮整次问答。系统会记录警告并继续只用向量召回；问题切不出任何词元时也会跳过关键词分支。混合检索解决的是召回覆盖问题，最终排序仍然交给重排模型。
