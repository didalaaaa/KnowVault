## 1. 交付目标

把 P0–P5 的能力包装成陌生人可复现的开源作品：

1. `cp .env.example .env` → 填两个模型 Key → `docker compose up -d --build` → 打开 <http://localhost:8080>。
2. 首次启动自动迁移、种子演示账号、导入示例知识库与 7 份多格式文档。
3. README 首屏能看懂定位、架构、截图、快速开始与演示账号。
4. MIT LICENSE + 第三方许可清单 + 仓库与镜像内无真实密钥。
5. 干净克隆 + 干净数据卷走完十步陌生人测试。

P6 不新增检索/问答业务能力，不部署上线，不启用多租户，不做 Gitee Go。

## 2. 一键启动

```bash
cp .env.example .env
# 编辑 .env：DEEPSEEK_API_KEY / SILICONFLOW_API_KEY
docker compose up -d --build
docker compose ps
docker compose logs -f demo-seed
```

打开 <http://localhost:8080>，使用 `demo / 1q2w3E*` 登录（仅本地演示）。重置数据：

```bash
docker compose down -v
```

服务、端口、配置与排错见 [`docs/docker-compose.md`](docker-compose.md)。

## 4. 架构要点

![架构](assets/architecture.svg)

- 浏览器只访问 nginx 8080；nginx 同源反代 API、OpenIddict、SignalR。
- Compose 固定 Production + HTTP + 构建期自签 OpenIddict 证书，issuer 固定为 `http://localhost:${KNOWVAULT_HTTP_PORT}`（默认 8080）。
- `migrator` 一次性完成迁移与种子；`demo-seed` 在 API 健康后导入示例数据。
- Redis 通过 `Volo.Abp.Caching.StackExchangeRedis` 接入，不再回落到进程内缓存。

## 6. 合规与安全

- 仓库许可：MIT。
- 代码依赖无 AGPL/SSPL；MinIO 与 Redis 以未修改官方镜像运行，不与代码静态链接，口径见 `THIRD-PARTY-LICENSES.md`。
- `.env`、`appsettings.secrets.json`、`openiddict.pfx` 被 `.gitignore` 与 `.dockerignore` 排除。
- `docs/driver/问题/` 与 `docs/interview/` 已移出公开树（本地保留于 `本地私有目录/`）。
- 演示口令、默认数据库/中间件口令仅本地使用，公网部署前必须全部更换。

## 8. 已知限制

- 仅本地演示：HTTP、默认口令、演示账号，不适合公网。
- 未做多租户、OCR、外部数据源、开放 API、移动端。
- 未做 HTTPS/域名/WAF/限流/备份/高可用。
- Gitee Go CI 后置；当前提供本地质量门禁命令。
- P4 旧 Qdrant 数据卷升级需重建向量索引，见 `TECH_STACK.md` §9.7.3。
